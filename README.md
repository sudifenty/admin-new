# SmartPle Admin — Remote Control (Phase 1)

UI-only React + Tailwind dashboard using mock student data and browser `localStorage`. There is no backend or student-app connection in this phase.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Local demo storage

- `global_daily_limit`
- `class_daily_limits`
- `smartple_students`

The Phase 2 integration outline is in [`docs/phase-2-integration-plan.md`](docs/phase-2-integration-plan.md).
