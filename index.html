LIVE CONNECTION

Connect to the student app’s Supabase project

The student app’s project URL and publishable key are prefilled. Existing student and admin Auth accounts work here without being copied. These are client-side values; never enter a service-role secret. For live Supabase mode, serve this file from an http(s) site; some browsers block API requests from file:// URLs.

Database setup SQL (copy into Supabase SQL Editor)

Copy and run the full schema-plus-seed setup first. Then run `authorize_qa_admin.sql`, `secure_smartple_profiles.sql`, and finally the read-only verifier, in that order. The browser cannot safely execute schema changes; use the existing student app project’s SQL Editor.

Auth uses the existing SmartPle project; Q-A profile/class data is synchronized from smartple_profiles. Admin access also requires the owner-managed daily_qa_admins allowlist.
