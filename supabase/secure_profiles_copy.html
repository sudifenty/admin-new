Secure SmartPle profile access

This transactional patch removes the reported allow-all policies and client grants, then enables RLS with student-own read and SmartPle-admin read/update. It changes permissions and policies only; it does not alter profile rows.

Run only in the existing student-app project, as project owner. It stops if other, unexpected policies are present.

Impact: anonymous profile access will stop. Authenticated students can read their own profile; admins can read and update profiles for existing admin controls. Direct student writes are denied. Do not run if an anonymous profile workflow must remain available; review that flow first.
If clipboard access is blocked, click inside the SQL box, press Ctrl+A (or ⌘A), then Ctrl+C (or ⌘C).
